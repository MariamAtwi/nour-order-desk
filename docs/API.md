# API Documentation – Nour's Order Desk

## Endpoints

### GET /api/orders
Returns `200` and an array of all existing orders.

### GET /api/orders/:id
Returns `200` with the matching order, or `404` if the ID does not exist.

Example response:
```json
{
  "message": "order is found",
  "order": {
    "id": "order-123",
    "customerName": "Maya",
    "phone": "00000",
    "productName": "Vanilla Candle",
    "quantity": 3,
    "unitPrice": 8,
    "total": 24,
    "status": "Pending"
  }
}
```

### POST /api/orders
Creates a new order after validating the submitted data.

Request:
```json
{
  "customerName": "Mariam",
  "phone": "00000",
  "productName": "Vanilla Candle",
  "quantity": 3,
  "unitPrice": 8
}
```

Response `201` with the created order. The server generates the ID, calculates the total, and assigns the default status `Pending`.

### PATCH /api/orders/:id
Updates selected fields of an existing order without replacing the entire order.

Example request:
```json
{
  "quantity": 4,
  "status": "Preparing"
}
```

Returns `200` with the updated order. Omitted fields remain unchanged, and the server recalculates the total when quantity or unit price changes.

The `id` and `total` fields cannot be modified by the client.

### DELETE /api/orders/:id
Deletes the order matching the provided ID.

Returns `204` with no response body, or `404` if the ID does not exist.

## Validation Rules

- `customerName`, `phone`, and `productName` are required and cannot be blank.
- Text fields are trimmed before storing.
- `quantity` must be a positive integer greater than or equal to 1.
- `unitPrice` must be a finite, non-negative number with at most two decimal places.
- `status` must be `Pending`, `Preparing`, or `Delivered`.
- `total` is calculated by the server: `quantity × unitPrice`.
- `id` is generated by the server.
- PATCH must contain at least one editable field.
- All supplied PATCH fields are validated before modifying the stored order.
- Malformed JSON returns `400 Bad Request`.

## Status Codes

| Code | Meaning |
|---|---|
| `200` | Request successful (GET and PATCH) |
| `201` | Order created |
| `204` | Order deleted, no response body |
| `400` | Invalid input or malformed JSON |
| `404` | Order ID not found |
